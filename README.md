# LumiFox

Кастомная мод для Minecraft (NeoForge 1.20.4), добавляющий умную лисичку Lumi.

## Особенности

- **Лисичка Lumi** — дружелюбная пассивная лиса, которая следует за игроком со сладкими ягодами
- **Яйцо призыва** — кастомное яйцо оранжево-голубого цвета для призыва Lumi
- **Кастомная вкладка** — отдельная вкладка Creative Mode для предметов мода
- **Размножение** — LumiFox можно размножать сладкими ягодами
- **Кормление** — лису можно лечить сладкими ягодами (+2 HP)

## Установка

1. Установите [NeoForge 20.4.251](https://neoforged.net/) для Minecraft 1.20.4
2. Скачайте файл `lumifox-1.0.1.jar` из раздела [Releases](../../releases)
3. Поместите jar-файл в папку `mods` вашего сервера/клиента

## Сборка

```bash
gradlew.bat build
```

Собранный jar будет доступен в   `build/libs/lumifox-1.0.1.jar`.

## Технологии

- **Minecraft**: 1.20.4
- **NeoForge**: 20.4.251
- **Java**: 17
